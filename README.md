# 全球手办与收藏模型分布图

手办、扭蛋、盲盒、GK 与角色模型的世界版图。54 个国家与地区的规模估算、27 个产业节点，
三种读法切着看：**市场总量**、**人均浓度**、**产业分工**。

在线看：<https://peipei707.github.io/figure-world-map/>
（本地看的话，把 `index.html` 下载下来用浏览器打开就行。）

## 它是怎么做的

- **单个 HTML 文件，零外部请求。** 底图、数据、样式、脚本全部内联，字体只用系统字体，
  离线和内网都能打开。`build.js` 会在构建时检查，页面里再出现远程 `src` / `href` 就直接失败。
- **关掉 JavaScript 照样能用。** 地图、图例、排行榜、厂商构成、节点列表都是构建时烘好的
  静态 HTML；三个视图之间的切换和产业角色筛选由单选框 + CSS 完成，不依赖脚本。
- **地图下方是全量数据表。** 54 行数值和说明都是静态 HTML，既方便直接查数，也是这张
  地图的无障碍替代。每个国家和城市节点还带 SVG `<title>`，不跑脚本也有原生提示。
- 运行时的脚本只做一件事：把光标指到的国家或节点写进右上角的读数框。

## 改数据 / 重新生成

```sh
node build.js      # 读 data/*.json + template.html，生成 index.html
```

没有依赖，Node 18 以上即可。数据分四份：

| 文件 | 内容 |
| --- | --- |
| `data/world.json` | Natural Earth 110m 底图，已按 Miller 投影烘成 SVG path |
| `data/countries.json` | 国别估算：中文名、规模（亿美元）、人均（美元）、产业角色、备注 |
| `data/nodes.json` | 展会 / 制造 / 总部 / 集散四类城市节点 |
| `data/firms.json` | 厂商收入的地区构成 |

配色、分级断点、视图定义都集中在 `build.js` 顶部，CSS 里的色阶规则由它生成，
所以改一处颜色，地图、图例、排行条会一起跟着变。

## 数字怎么来的，别跳过

**口径打架。** 这个品类没有各国通用的定义，所以「全球规模」没有可信的单一数字。英文行业报告
统计的是 action figures，把北美算成 38–42%、亚太只有 18–27%；亚洲口径的「手办／フィギュア」
把景品、扭蛋、盲盒、GK、拼装都算进来，于是亚太变成约 58%。各家给出的全球总额从 85 亿到
167 亿美元不等。**本图采用亚洲口径（广义角色模型），全球基数取 140 亿美元。**

**国别数值是估算。** 没有任何机构按国家公布这个品类的销售额。图上的国别数字是按区域比例、
人口和该国动漫零售活跃度拆出来的**量级估算**，用于比较相对位置，**不能当统计数据引用**。
「人均」= 该国估算规模 ÷ 总人口，不是玩家人均消费。

**一手来源**（页脚有完整版）：AJA《アニメ産業レポート 2025》、IOEA 活动统计、
Bandai Namco IR、Funko Form 10-K、POP MART 2025 年报（HKEX）、日本玩具协会／JACTA。
